# Emoji Face Tracker with Python and MediaPipe

A fun real-time face tracking project using OpenCV and MediaPipe that overlays a random emoji on the user's face via webcam. Hold up two fingers to freeze the emoji in place — perfect for interactive demos or playful webcam filters!

## Features

- Detects faces using MediaPipe
- Tracks hands to detect two raised fingers
- Overlays random transparent emojis on the detected face
- Emoji stops changing when two fingers are shown

## Requirements

- Python 3.7+
- OpenCV
- MediaPipe
- NumPy

Install dependencies with:

```bash
pip install opencv-python mediapipe numpy
```

## ▶️ How to Run
```bash
python main.py
```
